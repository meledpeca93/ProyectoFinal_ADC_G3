# Catálogo visual Dark Neon
Estos son mockups conceptuales diseñados durante la conversación; se usan para inspirar HTML/CSS/JS, **no son pantallas implementadas** ni datos reales. Los números/usuarios/fechas visibles son demostrativos: la lógica y los parámetros finales deben salir de Django. Los renders pueden mostrar ejemplos visuales incompatibles con las reglas (p. ej. puntajes en derrotas); siempre prevalece el documento del catedrático.
